# Attribution

This project uses hygiene rating data from the official UK Food Hygiene Ratings API (`api.ratings.food.gov.uk`).

Contains public sector information licensed under the [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).

Source: Food Standards Agency, [https://ratings.food.gov.uk](https://ratings.food.gov.uk).

FHRS data covers England, Wales and Northern Ireland. Scotland uses FHIS. A rating reflects the standard at the date of inspection, so the rating date should always be shown alongside the rating.

This project is independent and is not affiliated with or endorsed by the Food Standards Agency. It does not use FHRS or FHIS logos or official rating images.
